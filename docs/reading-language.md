# 双语归档与阅读语言

## 归档规则

- 英文主帖保存完整英文原文，再逐段翻译为简体中文。译文单独保存并标注，不把平台翻译或摘要当原文；评论保留原语言。翻译不改动出处、署名、时间、图片或原文中的判断与数字。
- 标题和正文可以同时离线阅读中、英两版。两版使用同一批本地图片，维持原文顺序和链接；不上传馆藏。旧归档可只补译文，无需重新抓取，也不生成第二条书架记录。
- 书架和阅读页右上角的「阅读语言」可选跟随系统、中文优先或原文优先。没有对应版本时显示原文；设置只存本机。搜索匹配两个版本的标题。「复制图文」采用当前显示的正文版本，勾选时附上原语言评论。
- 通过 Agent 备份时补齐译文；应用内直接粘贴链接或导入文件不会自动生成译文。独立打开原有 `index.html` 仍显示原文；星藏应用可读取译文。仅有原文的归档仍可照常使用。

## 离线补译文

```text
folio translation-source <归档ID>
folio add-chinese <归档ID> <译文.json>
folio verify <归档ID>
```

第一条输出 JSON。在本机将 `title` 和 `text` 改为简体中文，保持正文项的数量和顺序不变，保留 `source_sha256`；数字和已经合适的专名可原样保留。不要给译文插入 HTML。第二条验证它对应当前原文并另存为 `translation.zh-Hans.json`；相同译文重复提交不会写入，不覆盖已有不同译文。打开书架后确认中英文标题和正文可切换，正文配图顺序一致，评论和原文链接未改。验证已损坏或不匹配的译文应失败，阅读时则安全回退原文。
